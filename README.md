# NOVA NEXUS

> An interactive digital universe built by 4TVIBEZ.

NOVA NEXUS is a standalone frontend experiment designed to turn a website into an experience rather than a collection of pages.

## What is inside?

- 🌌 Animated canvas starfield with cursor-reactive depth
- 🖥️ Interactive terminal / command system
- ◈ Discoverable Nexus nodes with modal experiences
- ⚡ Live simulated system telemetry
- 🔊 Tiny Web Audio feedback engine
- 📱 Responsive mobile layout
- ✦ Hidden command and Easter-egg behavior
- 🚫 No frameworks or backend required

## Commands

Try:

`help` · `status` · `scan` · `whoami` · `clear`

There is also a secret command waiting to be discovered.

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static server.

## Built with

HTML5 · CSS3 · Vanilla JavaScript · Canvas API · Web Audio API
